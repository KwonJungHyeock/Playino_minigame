# 시범 수업 점검표 — 붉은 행성 대탈출(시범판)

정식 출시 전에 실제 교실 1~2곳에서 확인할 것들. 개발 환경(소프트웨어 3D · 가짜 보드)에서는 확인할 수 없는 항목만 모았다.
수업 한 번이 끝나면 아래 **기록 양식**을 채워 개발 쪽에 보내 주세요.

## 1. 수업 전날 (선생님 PC 1대로 10분)

| ✓ | 확인 | 방법 | 안 되면 |
|---|---|---|---|
| ☐ | 학교 PC 브라우저 | 크롬 · 엣지 · 웨일 최신판으로 게임 주소 열기 | 3D 미지원 안내 화면이 뜨면 → 설정 → 시스템 → '그래픽 가속 사용' 켜기 |
| ☐ | 3D 속도 | 타이틀 → 기지까지 들어가 걸어 보기. 끊기면 주소 뒤 `?q=low` | `?q=low` 에서도 끊기면 기기 사양(CPU · 그래픽) 적어 두기 |
| ☐ | 보드 연결 | 장비 점검 화면 → [보드 연결] → 포트 선택 → 13번 LED 깜빡임 | 아두이노 IDE · 시리얼 모니터 닫기 · 데이터 케이블인지 확인 |
| ☐ | 소리 | 미션 02(비콘)에서 부저 · 효과음 | 교실이면 `?class` (배경음악 끔) |
| ☐ | 기록 파일 | 기지 📒 일지 → 💾 기록 파일 받기 → 다른 PC 타이틀에서 📂 불러오기 | 다운로드 차단 정책 확인 |
| ☐ | 보고서 PDF | 📒 일지 → 📄 보고서 PDF | 다운로드 폴더 · 제출 경로 정하기 |

## 2. 수업 중 관찰 (보조 교사 · 관찰자)

| 무엇을 | 어떻게 적나 |
|---|---|
| **미션별 막힌 곳** | 미션 번호 · 단계 · 몇 명이 몇 번 실패했는지(도우미 모드가 켜진 학생 수) |
| **난이도** | 미션마다 "쉬움 / 적당 / 어려움" 손들기 · 통과까지 걸린 시간(일지에 남음) |
| **3D 속도** | 끊긴 PC 번호 · 어느 장면에서(기지 / 미션 / 발사 쇼) |
| **보드** | 연결 실패한 자리 · 실패 문구 · 해결 방법 |
| **이해도** | 강의 카드 퀴즈 첫 시도 정답(보고서에 자동으로 남음) · 학생이 코드 한 줄을 말로 설명할 수 있는지 |
| **보너스** | 도전 챌린지 '운석 폭풍 런' 완주 학생 수 · 고른 난이도 · 평균 떨어짐 수(결과 창) |
| **집중** | 다른 탭으로 새는 학생 · 꾸미기에만 오래 머무는 학생 |

## 3. 모둠 협동 (AWS 방 서버 또는 교실 모드)

AWS 서버 전이라면 **교실 모드**: 선생님 PC 에서 `npm run classroom` → 창에 나온 `http://선생님PC:8787/?v4=coop` 를 학생 PC 에 입력(`server/README.md`).

| ✓ | 확인 |
|---|---|
| ☐ | 방 서버 상태: `https://방서버주소/health`(교실 모드면 `http://선생님PC:8787/health`) → `{"ok":true}` |
| ☐ | 교실 모드: 학생 PC 에서 주소가 열리는지 — 안 열리면 선생님 PC 방화벽(개인 네트워크 허용) · 학교 와이파이 기기 간 차단(핫스팟으로 대신) |
| ☐ | 난이도(대기실에서 방장이 고름): 학년에 맞는 단계로 시작 → 완주 시간 · 막힌 장치를 단계별로 적기 |
| ☐ | 모둠 5명이 각자 PC 에서 기지 → 👥 모둠 → 방 코드로 대기실에 모두 보이는지 |
| ☐ | 출발 뒤 친구 에디가 부드럽게 움직이는지(끊김 · 순간이동 정도) |
| ☐ | 장치 5개(발판 문 · 다리 · 시소 · 컨테이너 · 팀 문) 를 모둠이 몇 분 만에 통과하는지 · 어디서 가장 오래 막히는지 |
| ☐ | 방장이 중간에 나가도 계속되는지 |
| ☐ | 학교 방화벽에서 `wss://` 연결이 막히지 않는지(막히면 정보 담당 선생님께 서버 주소 허용 요청) |

## 5. 정식 출시 전 남은 결정

- **로그인**: 시범판은 이름 · 번호만 받는다(`src/scenes/login.js` `ACCESS_CODE = false`). 판매판은 접속 코드 칸을 켜고 코드 확인 서버를 붙인다.
- **모둠 협동**: 방 서버(AWS, `server/README.md`)를 올리고 `VITE_ROOM_URL` 을 넣으면 기지에 👥 모둠 단추가 나타난다(주소가 없으면 숨김).
  그 전에는 교실 모드(`npm run classroom`, 선생님 PC = 게임 + 방 서버)로 같은 와이파이에서 한다 — 교실 주소에선 👥 모둠 단추가 늘 보인다.
- **난이도 기본값**: 처음은 '보통'. 반 전체를 묶으려면 주소 뒤 `?level=easy|normal|hard`.
- **개인정보 안내**: 학생 이름 · 번호는 그 기기 브라우저에만 저장된다. 모둠 방에서는 이름(8글자)과 에디 모습만 방 서버를 거쳐 친구 화면에 보이고 서버에 저장하지 않는다. 학교 배포 문서에 이 내용을 담는다.

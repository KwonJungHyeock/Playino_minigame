BEFORE CLASS2. 수업 전 준비

기기 · 브라우저

  • 보드를 연결하는 PC: 데스크톱 Chrome 또는 Edge(Web Serial 지원). 크롬북도 Chrome 이면 됩니다.
  • 태블릿 · 휴대폰: 게임은 화면 조작(띠 · 다이얼 · 단추)으로 끝까지 할 수 있지만, 보드 연결은 되지 않습니다.
  • 3D 화면은 기기 성능에 맞춰 화질을 스스로 낮춥니다. 아주 느린 기기는 주소 끝에 ?q=low 를 붙이면 처음부터 가벼운 화질로 시작합니다.

교실 수업 모드(권장)

학생 PC 즐겨찾기를 …/?class 주소로한 번 열면 그 기기에 저장됩니다(해제는 ?class=0). 배경음악 자동 재생 끔(30대가 동시에 틀면 부저 소리를 구분할 수 없어요) · 효과음 절반 · 첫 클릭에 전체화면(다른 탭으로 새는 것 방지).

학생 기록 운영

  • 기록은 그 기기의 브라우저 안에만 저장됩니다(서버로 보내지 않음). 학생 이름 · 번호는 첫 화면에서 받고, 보고서 PDF 에 그대로 들어갑니다.
  • 공용 PC: 다음 반 학생은 타이틀의 ‘새로 시작’ → 이전 기록을 지우고 이름부터 다시. 보드 연결 상태와 기기 설정은 남습니다.
  • 다른 PC 로 옮기기: 기지 오른쪽 위 📒 일지 → 💾 기록 파일(수백 바이트 ~ 수백 KB) → 새 PC 타이틀의 📂 다른 기기 기록 불러오기. USB · 학급 드라이브 · 메신저로 옮기면 됩니다.

WIRING3. 부품 · 핀 연결표

게임 안 결선 안내 · 강의 카드 · 탐사 보고서에 나오는 번호와 같습니다. 같은 핀을 여러 미션이 함께 씁니다(A0 = 조도 센서 또는 가변저항 — 미션에 맞게 바꿔 꽂기).

부품핀쓰는 미션핵심 코드
LED 3개(초록 · 노랑 · 빨강)D2 · D3 · D401 착륙 유도등digitalWrite(2, HIGH); delay(500);
피에조 부저D502 비콘 · 발사 쇼tone(5, 392); noTone(5);
RGB LED(네오픽셀)D603 에너지 셀 · 07 동굴 · 발사 쇼led.setPixelColor(0, 255, 225, 30);
조도 센서A004 태양광 · 07 동굴int v = analogRead(A0); if (v < 473) …
가변저항(다이얼)A005 로버 · 08 원자로 · 발사 쇼map(v, 0, 1023, 0, 255)
택트 버튼 2개D4 · D506 방어막 · 발사 쇼(D4)if (digitalRead(4) == HIGH) …
보드 내장 LEDD1308 원자로delay(map(d, 0, 430, 90, 720));
D4 · D5 를 두 가지로 써요01 착륙(D4 = 빨강 LED) · 02 비콘(D5 = 부저) · 06 방어막(D4 · D5 = 버튼). 차시마다 그 미션의 결선 안내 화면을 먼저 띄우고 그대로 꽂게 하세요.

보드 없이도 됩니다

모든 미션은 화면의 띠 · 다이얼 · 단추(또는 키보드 ←→ · 1 2 3 · 스페이스)로 끝까지 할 수 있습니다. 보드가 부족하면 2인 1조로 한 명은 보드, 한 명은 화면을 맡게 하고 다음 판에 바꿉니다.

미션 하나의 짜임(모든 미션 공통)

  1. 결선 안내 — 꽂을 부품과 핀. [보드 연결] 단추로 바로 연결 확인
  2. 바이저 강의 — 카드 3장. 코드 한 줄마다 단추를 누르면 3D 장면(과 보드)에서 실제로 일어남
  3. 확인 퀴즈 — 3문제 · 3지선다. 틀리면 탓하지 않는 힌트 후 다시(메달과 무관)
  4. 단계별 게임 — 2~3단계. 정확도 80% 이상이면 통과. 단계 설명 창에서 🧪 자유 실험 · 🔭 둘러보기 · 💡 원리 다시 보기
  5. 결과 — 등급 · 별 · 📷 기념사진. 통과하면 로켓 부품 장착

1차시 · 오리엔테이션 · 에디 꾸미기 · 부팅 훈련 준비 차시

목표: 게임의 흐름을 알고 보드를 연결한다 · 입력/처리/출력을 말로 설명한다
  • 타이틀 → 이름 · 번호(보고서에 들어가니 정확히) → 에디 꾸미기(이름은 ‘에디’ 그대로 또는 별명) → 보드 연결
  • 기지 인트로를 함께 보고, 오른쪽 위 🎨 꾸미기 · 📷 사진 · 📒 일지를 짚어 준다
  • 프롤로그 부팅 훈련으로 ‘센서(입력) → 보드(처리) → LED · 소리(출력)’ 개념 잡기
관찰: 보드 연결이 안 되는 자리는 7장 문제 해결표로. 이 차시엔 등급보다 흐름 익히기가 먼저

2차시 · 01 착륙 유도등 디지털 출력

부품: LED 3개 D2 · D3 · D4 · 단계: 타이밍 쇼 → 라이트 연주
digitalWrite(2, HIGH);   // 켜기
delay(500);              // 0.5초 기다리기
digitalWrite(2, LOW);    // 끄기
  • 보급선이 내려오는 박자에 맞춰 유도등을 켠다 — ‘켜는 순간’을 코드로 정하는 것이 타이밍
  • 🧪 자유 실험: 1 · 2 · 3 으로 유도등 무늬 맞추기 — digitalWrite(pin, HIGH/LOW) 와 마지막 명령 뒤 지난 시간(delay)이 위에 보인다
확장 질문: delay 를 절반으로 줄이면 빛 쇼는 어떻게 달라질까?

3차시 · 02 구조 신호 비콘 · 03 에너지 셀 소리 · 빛 출력

부품: 부저 D5 · RGB LED D6 · 단계: 작은별 → 환희의 송가 / 쉬운 색 → 어려운 색
tone(5, 392);                         // 솔(392Hz)
led.setPixelColor(0, 255, 225, 30);   // 빨강 + 초록 = 노랑
led.show();
  • 비콘: 레인(D/F/J 또는 1 2 3)을 박자에 맞춰 — 주파수가 높을수록 높은 음. 자유 실험에서 ↑↓ 로 옥타브(×2)를 바꿔 들어 보기
  • 에너지 셀: R · G · B 띠를 섞어 셀 색 만들기. 자유 실험의 ‘이 색 만들기’(노랑 · 자홍 · 하늘 · 흰색 · 분홍 · 연두)
확장 질문: 빛은 섞을수록 밝아지는데, 물감은 왜 어두워질까?

4차시 · 04 태양광 충전소 아날로그 입력 · 조건

부품: 조도 센서 A0 · 단계: 반딧불 신호 → 반딧불이 비행
int v = analogRead(A0);       // 0 ~ 1023
if (v < 473) { /* 어둠 */ }    // 기준값보다 작으면 가렸다
  • 손으로 센서를 가렸다 떼며 빛 / 그림자 신호 보내기. 에디가 몸으로 센서를 가리는 모습과 숫자를 함께 보게 한다
  • 자유 실험 판독 줄: analogRead(A0) → v · if (v < 기준) → 참/거짓 — 교실 밝기에 따라 값이 달라짐을 발견
확장 질문: 창가 자리와 안쪽 자리의 v 값이 다른 까닭은? 기준값은 어떻게 정하면 좋을까?

5차시 · 05 로버 추력 조절 · 06 운석 방어막 입력 두 가지

부품: 가변저항 A0 · 버튼 D4 D5 · 단계: 협곡 점프 → 언덕 질주 / 운석 막기 → 방어막 명령
int p = map(analogRead(A0), 0, 1023, 0, 255);   // 범위 바꾸기
if (digitalRead(4) == HIGH) { shieldOn(LEFT); }  // 눌림
  • 로버: 다이얼로 추력을 초록 띠에 넣고 버티기(관성이 있어 ‘미리’ 돌려야 함 — 2번 연속 못 넘기면 도우미가 켜져요)
  • 방어막: 아날로그(여러 값) vs 디지털(두 값)을 비교하며 정리
확장 질문: 가변저항을 반만 돌리면 analogRead 는 얼마쯤? map 결과는?

6차시 · 07 어둠 동굴 탐사 입력 → 처리 → 출력

부품: 조도 센서 A0 + RGB LED D6 · 단계: 수정 깨우기 → 빛 따라가기 → 어둠의 보스
int hue = map(analogRead(A0), 900, 100, 0, 320);   // 가릴수록 색이 바뀐다
led.setPixelColor(0, color(hue));
  • 손 그림자로 등불 색을 바꿔 몬스터 고리 색에 맞추기. 3단계 보스는 색이 숨어 있어 밝기 · ‘삐’ 소리 단서로 찾는다
  • 센서 두 개를 묶는 첫 미션 — 앞 차시의 입력(4차시)과 출력(3차시)을 이어 보게 한다
확장 질문: map 의 900 과 100 을 바꾸면(100, 900) 무슨 일이 생길까?

7차시 · 08 원자로 진정 · 자유 실험 탐구 피드백 제어

부품: 가변저항 A0 + 보드 LED D13 · 단계: 제어봉 내리기 → 압력 맞추기(띠가 숨음) → 폭주 붙잡기
int d = abs(analogRead(A0) - target);   // 목표와의 차이
delay(map(d, 0, 430, 90, 720));          // 멀수록 느리게 깜빡
  • 경고등이 빨리 깜빡일수록 가깝다 — 눈이 아니라 신호를 보고 맞추는 경험
  • 남은 시간은 자유 실험 탐구: 아무 미션이나 골라 ‘값 하나를 바꿔 보고 결과를 적기’(부록 활동지 B)
배려: 깜빡임이 불편한 학생은 일시정지 → ‘화면 효과 줄이기’(초당 3번 이하)

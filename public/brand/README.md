# public/brand

배포에 그대로 실리는 정적 그림. 지금 쓰는 것은 `logo.webp`(에듀이노 로고) 하나뿐이다.

- 예전 2D 판(미니게임 표지 · 방 배경 · 결선도 · 2D 에디 리그 등)의 그림은 2026-10 시범판 정리 때 지웠다(git 기록에 남아 있다).
- 새 3D 장면의 그림 · 모델은 `src/assets/`(빌드가 해시를 붙여 넣는다)에 두고 `?url` 로 가져온다 — 여기에 절대경로(`/brand/…`)로 새로 넣지 말 것(`docs/refactoring.md`).
- 그림을 넣을 때는 `npm run assets`(PNG → WebP 변환).
